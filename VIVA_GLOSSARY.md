# Viva glossary (first version)

- **Dataset:** A structured collection of records.
- **Feature:** A column used by the algorithm, such as Python score or CGPA.
- **Clustering:** Grouping similar records without pre-existing labels.
- **K-Means:** An algorithm that assigns records to K groups using distance from cluster centres.
- **Centroid:** The centre/average position of a cluster.
- **Standardization:** Rescaling columns so differences in units or ranges do not dominate distance calculations.
- **Skill gap:** Required skill level minus student's current level, when positive.
- **Skill match:** A percentage estimate of how closely a student's scores meet the listed skill requirements. It is not a hiring probability.
